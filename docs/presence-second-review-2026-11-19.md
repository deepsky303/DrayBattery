[РИСК] Свойство Windows не содержит используемой здесь метки времени измерения. После отключения нельзя доказать, что неизменившийся процент — новое сообщение: он намеренно не возрождает запись. Замена сервисного источника также не считается новым образцом. Изменившийся процент на том же источнике остаётся значением **Windows**, а не живым измерением; настоящий vendor-отчёт возвращает яркий режим.

[РИСК] При длительной недоступности самого PnP-проверяющего потока последнее значение остаётся затемнённым с отметкой неопределённости до достоверного отсутствия. Так ошибка перечисления не подменяется утверждением об отключении. Для USB с неопознанной ролью, внешних агрегаторов и источников без точной физической связи бессрочное хранение не обещается. У WGI/XInput нет добавленной привязки к точному экземпляру; их прежняя эвристика подавления резервного источника не является полной идентификацией нескольких контроллеров.

[РИСК] На реальном оборудовании подтверждены только повторные безопасные чтения G903/G915 X через G HUB и стоимость перечисления PnP. Физические сценарии сна, извлечения, повторного подключения, classic/LE и другие производители проверены **на имитациях**, не на устройствах.
